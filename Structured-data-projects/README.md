# Structured Data Projects
Machine learning projects built on structured and tabular datasets.

---

## Projects

### Heart Disease Prediction
Binary classification project for predicting the presence of heart disease using structured medical data.

### Bulldozer Price Prediction
Regression project for predicting bulldozer sale prices using historical auction data.

---

## Concepts Practiced

| Area | Topics |
|---|---|
| Data | Preprocessing, Exploratory Data Analysis, Feature Engineering |
| Modelling | Binary Classification, Regression, Model Evaluation |
